bimpdf XMP namespace, version 1

The namespace URI https://bimpdf.com/ns/1/ (prefix bimpdf) labels a PDF as a .bim.pdf. It is declared in the file's XMP packet, which includes a PDF/A extension-schema block describing these properties. The URI changes only on a major format version.

PropertyTypeMeaning
bimpdf:formatVersionTextThe format version the file follows, for example 1.14.
bimpdf:conformanceTextcore or drawing.
bimpdf:archivalText, optionalpdfa-3b when the file also passes veraPDF as PDF/A-3b.
bimpdf:specURILink to the specification, https://bimpdf.com/spec.
bimpdf:readingHintTextOne sentence on how to read the file.

Producer identity uses the standard xmp:CreatorTool. Details: section 4 of the specification. The older pdfbim fields are described at /ns/1.0/.
