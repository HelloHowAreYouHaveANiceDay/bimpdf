bim·pdf Spec

pdfbim legacy XMP namespace, 1.0

Earlier bim-pdf exports write XMP fields in the namespace http://pdfbim.com/ns/1.0/ (prefix pdfbim). That URI points to this page. Readers MUST still read these fields; producers MAY keep writing them.

PropertyMeaning
pdfbim:versionThe packaging generation (2 so far). It is not the format version and MUST NOT be read as one.
pdfbim:generatorThe tool that wrote the file.

A file's format version comes from bimpdf:formatVersion (/ns/1/) or, for older files, from the "bim-pdf" field of elements.json. Detection order and migration rules: section 4 and section 7 of the specification.
