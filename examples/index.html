Validate a file

The validator is Node 20 or newer with no install step. Get the repository and run it on a file:

node validator/bimpdf-validate.mjs your-file.bim.pdf

It checks the base file (section 1), PDF-native constructs and their agreement with the sidecars (section 2), sidecars as Associated Files (section 3), the declaration (section 4) and the conformance level (section 5). The sidecar schemas are core's built validator, vendored byte for byte. Exit code 0 means valid at the declared level, 1 means errors, and --json prints a machine-readable report. Details are in section 5 of the specification.
